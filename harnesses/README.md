# Harness catalog

Each directory here contains one independently maintained experiment. Read its
README for owners, setup, compatibility, and limitations. These are experimental
integrations; a passing build is not a runtime compatibility guarantee.

When adding a harness, add a row to this table linking to its README and naming
its maintainers.

| Harness | Integration | Maintainers |
| --- | --- | --- |
| [jev](jev/README.md) | TypeSafe's Jev decision model, through System One | @ernoaapa |
